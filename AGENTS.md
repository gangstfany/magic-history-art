# Repository scope

This is `magic-history-art`, an independent Git repository. Verify `git remote -v` before committing.

Do not edit, copy over, commit to, or deploy sibling repositories as a side effect of this repository's content changes.

Follow this repository README for build/test/publish commands. The original `gangstfany/magic-history` repository is a recovery archive for this migration; new work belongs in these independent repositories.

Course changes must not update homepage `auth-release.json` or its pinned account version. Do not push private media or unpublished drafts.
