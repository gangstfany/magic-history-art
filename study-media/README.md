# 学习图片归档

按用户2026-10-27明确要求，公开存放此前只保存在本地的81张学习图片：74个补全视图和7张远程图片失败时的备用图。

`manifest.json`逐张保留作品ID、视图ID、教材页码、原始图片/摄影者信息、出处链接和图片身份说明，并增加SHA256及字节数。教材本地路径已改为文件名，没有上传整本教材、登录配置或其他本地私有文件。

公开存放不改变原有出处或使用声明；这里没有新增“开放授权”或“公有领域”的断言。

2026-10-27按用户“继续下一步”的要求，构建正式网页时接入74个缺失视图。`scripts/publish_study_media.py`逐条验证作品ID、视角ID、SHA256和字节数，只复制对应的74张图片，不发布本清单或整个归档目录。网页保留署名、出处和原有使用声明；该集成不把学习图片改成开放授权素材。

另外7张备用图继续只作仓库归档，不替换当前原图。源课程的图片/授权数据保留历史记录，发布产物由构建脚本生成，避免把原有未验证授权的素材误记为开放图片。文件仍可从GitHub仓库浏览和下载。
