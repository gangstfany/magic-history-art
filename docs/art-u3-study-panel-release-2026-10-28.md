# U3 地图与学习面板联动

用户确认原型后接入正式Unit3：概览显示51件作品、8个地区；点地图或右侧地区进入对应作品列表；点右侧作品同步定位地图并打开原有详情、比较；路径返回地区和单元。筛选数量及列表同步，手机端随页面阅读。Unit下拉保持可用，其他单元及All Units保留原面板。原型仅归档，不发布。

地图和列表支持鼠标及键盘双向高亮，原生密集地点展开按钮也参与。单件作品仅高亮自身及父地点，避免同地点全部作品一起高亮。原生地图选作前捕获当前视图，返回保留拖动位置；筛选变化清除旧视图缓存。

验证：515项Node测试、10项Python测试、250件作品校验通过，219公共文件构建通过。完整首页真实浏览器验证France5件→Chartres60→比较SantaSabina49→关闭→返回France及Unit3；书籍筛选5件/5地区；切Unit2无新面板且Unit可切换。390px手机内容宽372px、scrollWidth372px，列表点击区域至少76px，详情overflow可自然展开，无控制台错误。罗马6件作品展开后，键盘聚焦AP49只高亮AP49和对应列表项。

独立审查发现并修复原生选作视图缓存、密集按钮联动和同地点错误连带高亮。保留原有作品资料与图片署名；缩略图加载失败退回AP编号。
