Accessed 2026-10-13. Official reference: [College Board West and Central Asia image set](https://secure-media.collegeboard.org/digitalServices/pdf/ap/ap-art-history-ced-content-area-7-west-and-central-asia.pdf), PDF pages 4–9, printed pages 132–137. All six relevant pages were inspected in full before selection. This file records image decisions, not broader content attribution. Seventeen open local derivatives and three honest placeholders; 20 ordered stable view IDs. No CED images extracted and no hotlinks used by the page.

## Release policy and verification

Eligible image-level grants: public domain, CC0, CC BY, CC BY-SA. Commons page footer licenses do not apply automatically to the images. The grant cited below is each file’s own Licensing section. CC BY-SA derivatives retain their source license; credit, license link and conversion disclosure must accompany public display. Faithful 2D PD-Art reproductions are not warranties that every jurisdiction treats photographic reproductions identically. Media objects always use local paths or null.

All local sources were visually inspected and then proportionally resized (maximum edge 2000), EXIF orientation normalized where present, and converted to WebP. No additional crop, retouching, compositing or essential-content removal. Some downloads use Wikimedia's standard 1280-pixel-wide thumbnail after original-download rate limiting; original URL still recorded, thumbnail carries the same image rights. Full source frame is retained. The basin source already has background removed by its named Commons derivative creator. The Treasury source already has the photographer's perspective correction.
